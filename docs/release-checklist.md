# Release Checklist

## Functional
- [ ] Send from active tab opens URL in target profile.
- [ ] Optional close-original-tab works after successful launch.

- [ ] Host launch uses arg list, not shell strings.

## Compatibility
- [ ] Windows 10 pass.
- [ ] Windows 11 pass.

## Documentation
- [ ] Setup docs updated.
- [ ] Protocol docs updated.
- [ ] Architecture docs updated.
